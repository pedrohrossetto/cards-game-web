# cards-game-web

Card battle game, built for the Web Page Creation course (IFSul, Computer Science, 2025/1). Part of my [studies](https://github.com/pedrohrossetto/studies) archive.

Each player creates cards with a name and damage (1–100, validated), then picks one card each to battle: the higher damage wins. Plain HTML, CSS and JavaScript.

**Live demo:** https://pedrohrossetto.github.io/cards-game-web/

Run locally by opening `index.html` in a browser.
