# cards-game-web

Jogo de batalha de cartas, feito na disciplina de Criação de Páginas Web (IFSul, Ciência da Computação, 2025/1). Faz parte do meu repositório de [estudos](https://github.com/pedrohrossetto/studies).

Cada jogador cria cartas com nome e dano (1–100, validado) e escolhe uma carta para a batalha: vence o maior dano. HTML, CSS e JavaScript puros.

**Demo:** https://pedrohrossetto.github.io/cards-game-web/

Para rodar localmente, abra `index.html` no navegador.
